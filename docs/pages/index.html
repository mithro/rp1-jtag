The rp1-jtag apt repository has moved

This address no longer serves Debian packages. Packages and static binaries are published by fpgas.online-fpga-tools.

mithro/rp1-jtag is now the development repository for librp1jtag and its openFPGALoader and OpenOCD drivers. Its CI uploads binaries as workflow artifacts and publishes nothing installable.

New package names

Was, hereNow, at fpgas.online
openfpgaloader-rp1pioopenfpgaloader-fpgasonline or -fpgasonline-git
openocd-rp1pioopenocd-fpgasonline or -fpgasonline-git

The -git packages are built from a pinned snapshot of upstream master, the others from the latest upstream release. Both carry the RP1 PIO JTAG driver, so the rp1pio cable and the rp1_pio_jtag adapter keep their names.

Switching a host over

sudo rm -f /etc/apt/sources.list.d/rp1-jtag.list
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://fpgas.online/fpgas.online-fpga-tools/fpgas-online-fpga-tools.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/fpgas-online-fpga-tools.gpg
echo "deb [signed-by=/etc/apt/keyrings/fpgas-online-fpga-tools.gpg] \
  https://fpgas.online/fpgas.online-fpga-tools/$(. /etc/os-release; echo $VERSION_CODENAME)/ ./" \
  | sudo tee /etc/apt/sources.list.d/fpgas-online-fpga-tools.list
sudo apt update
sudo apt install openfpgaloader-fpgasonline-git openocd-fpgasonline-git

The new packages Conflict and Replace the old ones, so that apt install removes them in the same step. The gpg --dearmor matters: apt reads a keyring's format from its file extension, and armour saved under a .gpg name makes the repository read as unsigned on Debian 12.
